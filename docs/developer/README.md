# 普通开发者使用

普通开发者不需要在多篇文档之间查找。请选择一份主文档：

- [普通开发者完整指南（中文）](developer-guide.zh-CN.md) —— 推荐入口。
- [Developer Guide (English)](developer-guide.md)

中文完整指南一次覆盖：

```text
向管理员获取 MCP URL + Developer API Key
  -> 配置 Codex / Claude Code MCP
  -> 验证 teamSkillHub
  -> discover / 使用 Skill / Knowledge
  -> 创建完整 Skill 目录并提交 Skill Bundle
  -> 自动或手工回流 Knowledge
  -> 把 Candidate ID 发给管理员审批
  -> 管理员创建 PR/MR
  -> PR/MR 合并
  -> published
```

常见问题、Knowledge 生命周期、Candidate 审核状态和排障也已经合并到主文档，不再单独维护碎片文档。
